# Public source attribution and scope

Original URLs, pinned revisions where applicable, retrieval times and byte hashes
are in [sources.json](sources.json). Full source snapshots retain their original
content. The source material remains attributable to its upstream contributors;
this study does not relicense upstream projects.

- **Node.js Release:** [schedule and project](https://github.com/nodejs/Release).
  The preserved `schedule.json` is used for actual milestone dates, including
  scheduled future dates. See the upstream repository for its current notices.
- **endoflife.date:** [Python lifecycle](https://endoflife.date/python) and
  [API documentation](https://endoflife.date/docs/api). The preserved response is
  an API snapshot; it is not a statement that schedules cannot change.
- **SPDX license-list-data:** [project and notices](https://github.com/spdx/license-list-data)
  and [license list](https://spdx.org/licenses/). Only registry identifiers,
  names and detail links are used, not the underlying licensed software.
- **IANA:** [Media Types registry](https://www.iana.org/assignments/media-types),
  [application CSV](https://www.iana.org/assignments/media-types/application.csv)
  and [licensing terms](https://www.iana.org/help/licensing-terms).
  CSV `Name` and `Template` values are preserved; registration URLs are formed
  from the documented public registry base and actual template path.
- **Prometheus Operator:** [project](https://github.com/prometheus-operator/prometheus-operator),
  [Apache-2.0 license](https://github.com/prometheus-operator/prometheus-operator/blob/main/LICENSE).
  The original manifest and its decoded JSON are included. Only literal verb
  membership in a supplied rule block is tested, not full Kubernetes authorization.
  See [Kubernetes RBAC documentation](https://kubernetes.io/docs/reference/access-authn-authz/rbac/).
- **Homebrew:** [Formula JSON API documentation](https://formulae.brew.sh/docs/api/)
  and [homebrew-core project/notices](https://github.com/Homebrew/homebrew-core).
  The five preserved formula responses supply actual available bottle tags,
  not installation recommendations or a guarantee that a bottle remains available.

No personal user requests, private application records or developer-consent
claims are included. Upstream projects have not endorsed this study. The prompts,
schemas, contracts, projections and independent checkers are study authorship.
