# Benchmark provenance

`cases.jsonl` contains **480 synthetic test cases**, generated by `heschema.dataset.generate_cases`. These are not copied public benchmark suites. Six domains have 80 cases each; `manifest.json` records counts and a SHA-256 fingerprint.

All labels are template-generated and automatically reference-checked; **none are claimed human-reviewed**. Reordered field lists are a limited form of paraphrase, not broad natural-language diversity. Review labels, add natural prompts/adversarial edge cases, and collect held-out real-domain tasks before generalizing measured effects.

`expected` is the hidden scoring oracle, while `prompt/context` are model-visible. A supplied input schema never replaces the reference scoring contract. Schema fixtures deliberately include weak and contradictory candidates for experiments; do not use those as trusted runtime contracts.

Rebuild with `heschema dataset --build`; audit with `heschema dataset`. See the root README for case format, metrics, costs, experiment arms, and inference limitations.
